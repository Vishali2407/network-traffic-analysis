# Network Traffic Analysis (Wireshark Labs)

## Objective
Hands-on practice using Wireshark to analyze real network traffic, understand protocols, and detect anomalies.

---

## Tools Used
- Wireshark (Network Protocol Analyzer)
- Kali Linux / Windows
- PCAP files

---

## Topics Covered
- DNS (Domain Name System)
- TCP (Transmission Control Protocol)
- UDP (User Datagram Protocol)
- HTTP (HyperText Transfer Protocol)
- HTTPS (HyperText Transfer Protocol Secure)
- IP Addressing (IPv4)

---

## Lab Structure

Each lab includes:
- Objective
- Filters used
- Packet analysis
- Observations
- Screenshots
- Key learnings

---

## Sample Filters
ip.addr == 192.168.119.128
dns
tcp
http
tcp.port == 443

---

## Goals
- Improve packet analysis skills
- Understand real network behavior
- Identify suspicious traffic patterns
- Build strong networking fundamentals
